MÓDULO 02 / CASO DE ESTUDIO

Ajustes presupuestarios de un pequeño café

El negocio necesita distribuir cambios de presupuesto entre áreas relacionadas sin tratar cada partida como una decisión aislada.

Desarrollo de Sistemas

Contexto financiero

Se modelan aumentos o reducciones respecto de un presupuesto base. El objetivo es acercarse a metas de cada área y, al mismo tiempo, evitar diferencias excesivas entre categorías vinculadas.

Las variables no representan el presupuesto total: cada unidad calculada equivale a Bs 100 de ajuste.

Procedencia y alcance de los datos

Los coeficientes son hipotéticos y académicos; no provienen de registros contables. Se eligieron para construir matrices simétricas definidas positivas y estudiar la convergencia.

El modelo no incorpora liquidez, flujo de caja, impuestos ni restricciones de no negatividad.

MÓDULO 03 / FORMULACIÓN

Del presupuesto al sistema Ax = b

La misma estructura matemática se conserva en los tres escenarios; solo cambian, de forma justificada, los objetivos, pesos o acoplamientos.

01

Definir objetivos

El vector t contiene el ajuste deseado para cada categoría, medido en centenas de bolivianos.

02

Equilibrar prioridades

Los pesos W priorizan áreas y las penalizaciones cᵢⱼ vinculan categorías relacionadas.

03

Obtener el sistema

Al imponer ∇J(x)=0 se obtiene (W+L)x=Wt; por tanto, A=W+L y b=Wt.

FUNCIÓN DE COSTO CUADRÁTICA
J(x) = ½(x − t)ᵀW(x − t) + ½Σ cᵢⱼ(xᵢ − xⱼ)²

Diagonal de A: prioridad propia más vínculos de cada categoría. Fuera de diagonal: acoplamientos −cᵢⱼ. Vector b: objetivos ponderados.

Demostración formal para los tres escenarios

Simetría: W=Wᵀ y el laplaciano L=Lᵀ; luego A=W+L=Aᵀ.

Definición positiva: para cualquier y≠0:

yᵀAy = Σ wᵢyᵢ² + Σ cᵢⱼ(yᵢ−yⱼ)² > 0

Como todos los wᵢ son positivos y cᵢⱼ≥0, la propiedad se cumple en ideal, estrés y mal condicionado.

Sistema lineal del escenario activo

Verificación numérica complementaria

Interpretación: modificar A manualmente permite experimentar, pero puede romper la estructura financiera W+L. Por eso la aplicación vuelve a comprobar simetría y Cholesky antes de ejecutar los métodos.

MÓDULO 06 / SOLUCIÓN DE REFERENCIA

Cholesky como método directo

Para cada escenario se factoriza A=LLᵀ y se resuelven Ly=b y Lᵀx=y. El resultado se denomina solución numérica de referencia.

Vector xref del escenario activo

Método directo · Cholesky
—

Se usa para calcular los errores del GCP componente por componente.

Secuencia del método

  1. Comprobar que A es simétrica definida positiva.
  2. Construir la matriz triangular inferior L.
  3. Resolver la sustitución hacia adelante Ly=b.
  4. Resolver la sustitución hacia atrás Lᵀx=y.
  5. Verificar el residuo ||b−Axref||₂/||b||₂.

MÓDULO 10 / CONCLUSIONES Y REFERENCIAS

Lectura técnica y financiera

IDEAL

Equilibrio presupuestario

Los ajustes se aproximan a las prioridades y mantienen coherencia entre categorías relacionadas.

ESTRÉS

Los objetivos desplazan la solución

Cambiar b modifica los ajustes; si A permanece igual, su condicionamiento no cambia.

CONDICIÓN

La estabilidad importa

El caso extremo muestra por qué deben analizarse residuos, errores y la utilidad real del precondicionador.

Conclusión general

El GCP produce soluciones consistentes con la referencia cuando A es simétrica definida positiva. Jacobi puede reducir las iteraciones si el problema dominante es el escalamiento diagonal, pero no garantiza una mejora universal ante acoplamientos fuertes. Financiera y éticamente, estos resultados son sugerencias condicionadas por un modelo académico, no órdenes automáticas de gasto.
